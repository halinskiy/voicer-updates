# Voicer Dev

Voicer Dev — полнофункциональное приложение для голосового ввода в macOS. Удерживайте Fn, говорите и отпустите: распознанный текст вставится у курсора.

Речь распознаётся локально через whisper.cpp и Whisper large-v3-turbo. Доступны автословарь, необязательная коррекция терминов через LM Studio, чистка русской речи и Sparkle-обновления. Приложение подписано Developer ID и распространяется вне App Store.

Скачать последнюю версию: [Voicer.dmg](https://github.com/halinskiy/voicer-updates/releases/latest/download/Voicer.dmg). Sparkle feed: [appcast.xml](https://halinskiy.github.io/voicer-updates/appcast.xml). Исходный код находится в приватном репозитории `halinskiy/voicer`.
